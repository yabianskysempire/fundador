Cómo gestionar proyectos en Notion con un tablero Kanban: guía paso a paso para emprendedores

Publicado el 26 de octubre de 2026 · Lectura: 6 min

Si llevas tu negocio solo o con un equipo pequeño, seguro conoces la sensación: tareas en cinco lugares distintos, ideas en el celular y la duda constante de qué toca hacer hoy. Un tablero Kanban en Notion resuelve gran parte de eso con una estructura simple: una sola base de datos, columnas que representan el avance y una rutina corta para mantenerlo vivo.

En esta guía armas el tablero desde cero, defines estados útiles, creas las vistas que realmente vas a usar y fijas un flujo semanal. Al final encontrarás los errores más comunes y cómo evitarlos.

Qué es un tablero Kanban (en una frase)

Un tablero Kanban muestra el trabajo como tarjetas que se mueven por columnas, de izquierda a derecha, según su estado: por ejemplo, de «Pendiente» a «En curso» y luego a «Hecho». Lo valioso es que ves de un vistazo qué está atascado, qué avanza y qué falta empezar.

En Notion, cada tarjeta es una página dentro de una base de datos, y el tablero es solo una forma de mostrar esa base de datos.

Paso 1: crea la base de datos de tareas

El error más frecuente es empezar por el tablero visual. Empieza por los datos.

  1. Crea una página nueva llamada «Proyectos y tareas».
  2. Dentro, agrega una base de datos a página completa (en la opción de base de datos, no una lista suelta).
  3. Ponle el nombre «Tareas».

Cada fila de esa base será una tarea o entregable. Mantén el título corto y con verbo: «Redactar propuesta para cliente», no «Propuesta».

Paso 2: define las propiedades mínimas

Cada propiedad extra es una cosa más que tendrás que mantener. Empieza con cinco:

  • Estado: en qué punto está la tarea (lo vemos en el paso 3).
  • Proyecto: una propiedad de selección o una relación con otra base de datos de proyectos.
  • Fecha límite: tipo fecha, solo cuando la tarea tiene un plazo real.
  • Prioridad: Alta, Media o Baja. Tres niveles bastan.
  • Responsable: útil si trabajas con alguien más; si estás solo, puedes omitirla.

Si manejas varios proyectos grandes, crea una segunda base de datos «Proyectos» y conecta las tareas con una relación. Si tienes pocos proyectos, una propiedad de selección es suficiente y más rápida.

Paso 3: configura los estados

Notion incluye una propiedad de tipo «Estado» que agrupa las opciones en categorías como «Sin empezar», «En curso» y «Listo» (los nombres pueden variar según el idioma de tu cuenta). Úsala para tus columnas.

Un conjunto de estados sencillo para emprendedores:

  1. Bandeja: ideas y tareas capturadas, sin decidir todavía.
  2. Esta semana: lo que te comprometes a hacer en los próximos siete días.
  3. En curso: lo que estás haciendo ahora.
  4. En espera: depende de otra persona o de algo externo.
  5. Hecho: terminado.

Regla útil: cada estado debe responder a una pregunta distinta. «Bandeja» responde «¿qué se me ocurrió?», «Esta semana» responde «¿qué decidí hacer?» y «En espera» responde «¿qué no depende de mí?». Si dos estados responden lo mismo, fusiónalos.

Paso 4: crea la vista de tablero

Ahora sí, el tablero visual.

  1. En la base de datos «Tareas», agrega una nueva vista.
  2. Elige el tipo Tablero.
  3. Agrúpalo por la propiedad Estado.
  4. Oculta las propiedades que no necesitas ver en la tarjeta; deja visibles solo la fecha límite y la prioridad.

Prueba mover una tarjeta de una columna a otra arrastrándola. El estado de la tarea cambia solo.

Paso 5: agrega las otras vistas que sí vas a usar

Una base de datos puede tener varias vistas, cada una con sus propios filtros y orden. Con tres vistas cubres casi todo:

  • Tablero semanal: filtrado para mostrar solo las tareas en «Esta semana», «En curso» y «En espera». Es la vista que abres cada día.
  • Bandeja: una lista filtrada por estado «Bandeja», para revisar y decidir.
  • Por proyecto: un tablero o tabla agrupada por Proyecto, para ver el avance de cada uno.

Puedes añadir un calendario filtrado por fecha límite si trabajas con plazos de clientes. Evita crear más de cuatro vistas: si no abres una en dos semanas, bórrala.

Paso 6: un flujo semanal de 30 minutos

El tablero solo funciona si lo actualizas con ritmo. Esta rutina cabe en media hora.

Viernes o domingo (15 minutos): planificar

  1. Abre la vista «Bandeja» y decide para cada tarjeta: pasa a «Esta semana», queda para más adelante o se elimina.
  2. Revisa «En espera»: ¿hay algo que debas reclamar o recordar?
  3. Elige un máximo de cinco a siete tareas para «Esta semana». Si pones veinte, ninguna se terminará.

Cada día (5 minutos): ejecutar

  1. Abre el tablero semanal.
  2. Mueve a «En curso» solo una o dos tarjetas.
  3. Al terminar, pasa la tarjeta a «Hecho».

Cierre de semana (10 minutos): revisar

  1. Mira la columna «Hecho»: ¿qué lograste?
  2. Las tareas que quedaron sin hacer: vuelve a decidir si siguen siendo importantes.
  3. Anota una cosa que cambiarías la próxima semana.

Errores comunes y cómo evitarlos

1. Demasiadas columnas. Con ocho o diez estados, mover tarjetas se vuelve una tarea en sí. Quédate con cinco o menos.

2. Demasiadas tareas en curso. Notion no te limita cuántas tarjetas puedes poner en «En curso», así que ponte tú el límite: dos como máximo. Terminar es más valioso que empezar.

3. Tareas vagas. «Marketing» no es una tarea; «Escribir el correo de bienvenida» sí. Si no sabes cuál es el primer paso, la tarjeta no está lista.

4. Mezclar ideas con compromisos. Si todo está en el mismo lugar sin distinguir, el tablero se llena de ruido. Para eso existe «Bandeja» frente a «Esta semana».

5. Propiedades que nadie llena. Si después de un mes una propiedad está vacía en la mayoría de las tarjetas, elimínala.

6. No revisar nunca. Un tablero desactualizado es peor que no tener tablero, porque genera falsa confianza. Protege tus 30 minutos semanales como una reunión con un cliente.

7. Rediseñar en vez de trabajar. Es tentador pasar horas ajustando colores e íconos. Usa el sistema dos semanas tal como está antes de cambiar nada.

Checklist para empezar hoy

  • [ ] Crear la base de datos «Tareas».
  • [ ] Añadir las propiedades: Estado, Proyecto, Fecha límite y Prioridad.
  • [ ] Definir cinco estados.
  • [ ] Crear la vista de tablero agrupada por Estado.
  • [ ] Capturar en la bandeja todo lo que tienes pendiente en la cabeza.
  • [ ] Elegir cinco a siete tareas para esta semana.
  • [ ] Poner un recordatorio semanal de 30 minutos en tu calendario.

Para cerrar

Un buen tablero Kanban no es el más bonito, sino el que abres todos los días sin pensarlo. Empieza con pocos estados, pocas propiedades y una rutina semanal corta; ajusta solo cuando notes un problema concreto. En un par de semanas sabrás qué te sobra y qué te falta.
